3. One-time setup

  1. Install Docker Desktop for Windows (docker.com/products/docker-desktop — default install options are fine).
  2. Unzip the file you downloaded into one folder — anywhere is fine, e.g. your Desktop.
  3. Open Docker Desktop and wait until it says it's running.
  4. Double-click update.bat inside that folder. First run takes a few minutes (downloading everything) — it'll say "Update complete" when done.

Every time before a demo

  1. Open the Docker Desktop app (it does not start automatically on login). Wait about a minute.
  2. Open a browser to https://localhost:8443.
  3. A security warning is expected and normal — it's a self-signed certificate, not a real problem. Click "Advanced" → "Proceed" (Chrome) or equivalent.
  4. Log in with the Super Admin email/password you were given separately.
